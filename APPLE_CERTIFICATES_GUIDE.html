1. Requisitos Previos

Antes de comenzar, necesitas:

  • Cuenta Apple Developer con membresía activa ($99/año)
  • Acceso a https://developer.apple.com/account
  • Team ID y Pass Type ID (obtenido en Wallet Console)
  • Mac con Keychain Access (o software de gestión de certs)
  • OpenSSL instalado en terminal (macOS lo trae)
Nota importante: Ten en cuenta tu Team ID (10 caracteres alfanuméricos). Lo necesitarás en cada paso.

2. Obtener Wallet Signing Certificate (.p12)

Este es el certificado que usaremos para firmar los pases .pkpass.

Paso 1: Generar una Certificate Signing Request (CSR)

En tu Mac, abre Terminal y ejecuta:

openssl req -new -newkey rsa:2048 -nodes -keyout pass-signing.key -out pass-signing.csr -subj "/CN=Pass Signing Certificate"

Esto genera dos archivos:

  • pass-signing.key (clave privada)
  • pass-signing.csr (solicitud)

Paso 2: Crear un Pass Type ID (si no lo tienes)

1. Ve a: https://developer.apple.com/account/resources/identifiers/list
2. Click + (arriba a la derecha)
3. Selecciona Pass Type IDs
4. Click Continue
5. Ingresa Descripción: Fideliza Loyalty Pass
6. Ingresa ID: pass.{TU_TEAM_ID}.fideliza
7. Click Register → Done

Paso 3: Crear Wallet Signing Certificate

1. Ve a: https://developer.apple.com/account/resources/certificates/list
2. Click + (arriba a la derecha)
3. Selecciona Pass Type ID Certificate
4. Click Continue
5. Selecciona tu Pass Type ID que acabas de crear
6. Click Continue
7. Sube el archivo pass-signing.csr que generaste en Paso 1
8. Click Continue → Download

El archivo se descargará como pass.cer. Guárdalo.

Paso 4: Convertir .cer a .p12

Opción A: Usando openssl (recomendado)

openssl pkcs12 -export -in pass.cer -inkey pass-signing.key -out pass-signing.p12 -name 'Wallet Signing'
Te pedirá una contraseña: ingresa algo seguro (la necesitarás luego).

Opción B: Usando Keychain Access (macOS)

  • Doble-click en pass.cer para importarlo a Keychain
  • Abre Keychain Access (Aplicaciones → Utilidades)
  • Busca Wallet Signing (o el CN que usaste)
  • Right-click → Export
  • Guarda como pass-signing.p12 con contraseña

3. Obtener WWDR Certificate

Este es el certificado intermedio de Apple que valida tu firma.

Opción A: Descargar manualmente

  • Ve a: https://www.apple.com/certificateauthority/
  • Busca Apple Worldwide Developer Relations CA 4
  • Descarga AppleWWDRCA4.cer

Opción B: Ya está en tu Mac

  • Abre Keychain Access → Busca Apple Worldwide Developer Relations CA 4
  • Si lo encuentras, Right-click → Export → Guarda como AppleWWDRCA4.cer

4. Obtener APNs Private Key (.p8)

Este es el certificado para enviar notificaciones push a los Wallets.

Paso 1: Crear una Authentication Key

1. Ve a: https://developer.apple.com/account/resources/authkeys/list
2. Click + (arriba a la derecha)
3. Selecciona Apple Push Notifications service (APNs)
4. Click Continue
5. Confirma el Team ID que aparece
6. Click Register

Paso 2: Descargar la clave

  • Te mostrará un botón Download
  • Descarga el archivo (será AuthKey_XXXXXXXXXX.p8)
  • Guárdalo en lugar seguro. No se puede descargar de nuevo.
⚠️ IMPORTANTE: Este es un archivo privado. Si lo pierdes, deberás crear una nueva clave.

Paso 3: Anotar el Key ID

En la pantalla de Apple Dev Console verás el Key ID (10 caracteres). Cópialo y guárdalo junto con el archivo .p8.

5. Exportar desde Keychain (si ya tienes certificados)

Si ya creaste estos certificados antes, probablemente estén en tu Keychain.

Paso a paso:

  • Abre Keychain Access (Aplicaciones → Utilidades)
  • En la barra de búsqueda, escribe pass o wallet
  • Encontrarás Wallet Signing Certificate (con un icono de candado 🔒)
  • Right-click → Export...
  • Selecciona formato Personal Information Exchange (.p12)
  • Guarda el archivo: pass-signing.p12
  • Ingresa la contraseña que usaste al crear el certificado

6. Notas de Seguridad

✅ DO (Haz esto):

  • Guarda los certificados en un lugar seguro
  • Usa contraseñas fuertes para los .p12
  • Nunca commitees los .p12 a git (deberán estar en .gitignore)
  • Nunca pastes las claves privadas en emails o chats públicos
  • Sube los certificados a Cloudflare como secrets (no en el código)

❌ DON'T (No hagas esto):

  • No compartas las claves privadas
  • No almacenes las contraseñas en archivos de texto
  • No uses estos certificados en múltiples aplicaciones
  • No dejes los .p12 en la carpeta de descargas

7. Estructura de Archivos Local

Una vez tengas todos los certificados, guárdalos en una estructura ordenada:

~/Apple/Wallet/ ├── pass-signing.p12 ├── AppleWWDRCA4.cer ├── AuthKey_XXXXXXXXXX.p8 └── notes.txt

El archivo notes.txt debe contener:

Team ID: XXXXXXXXXX Pass Type ID: pass.XXXXXXXXXX.fideliza APNs Key ID: YYYYYYYYYY Contraseña .p12: [tu_contraseña_segura]

8. Validación de Certificados

Validar .p12

openssl pkcs12 -in pass-signing.p12 -nodes -nokeys

Deberías ver un certificado válido sin errores.

Validar .cer

openssl x509 -in AppleWWDRCA4.cer -text -noout | head -20

Verifica que sea un certificado de Apple válido.

Validar .p8

openssl pkey -in AuthKey_XXXXXXXXXX.p8 -text -noout | head

Verifica que sea una clave privada EC válida.
